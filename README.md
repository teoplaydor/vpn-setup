# VPN-Setup

Установщик v2rayN в один заход: скачивает свежую версию, добавляет профиль
по вашей ссылке и настраивает всё под российские условия.

## Скачать

**[VPN-Setup.exe](../../releases/latest/download/VPN-Setup.exe)** — установщик

**[NetRepair.exe](../../releases/latest/download/NetRepair.exe)** — восстановление
сети, если её сломал какой-нибудь VPN-клиент

## Как пользоваться

1. Скачайте `VPN-Setup.exe` и положите в любую папку — например, в «Загрузки».
2. Запустите. Вставьте ссылку подключения (`vless://...`) правым кликом.
3. Ответьте на два вопроса: нужен ли режим TUN и автозапуск.
4. Дождитесь загрузки — около 160 МБ.
5. Готово: на рабочем столе появится ярлык **VPN**. Запускаете — работает,
   нажимать ничего не нужно.

Рядом с установщиком создаётся папка `v2rayN` со всей программой. Больше
никуда ничего не пишется, в системные папки установщик не лезет.

## Что настраивается автоматически

| Параметр | Значение | Зачем |
|---|---|---|
| Ядро | Xray | sing-box не поддерживает транспорт XHTTP |
| `EnableLegacyProtect` | `false` | иначе TUN отдаётся sing-box, и XHTTP не работает |
| `StrictRoute` | `false` | оставляет правила брандмауэра и убивает сеть при сбое клиента |
| Стек TUN | gVisor | устойчивее на UDP, важно для голоса в Discord |
| MTU | 9000 | корректно для транспорта поверх TCP |
| Sniffing + DestOverride | `http, tls, quic` | без этого правила по доменам не работают |
| Системный прокси | вкл. без TUN, выкл. с TUN | вместе с TUN он лишний |
| Маршрутизация | РФ напрямую, остальное через VPN | банки и Госуслуги видят российский IP |

Правила маршрутизации намеренно опираются только на те категории, которые есть
в **любой** сборке geo-файлов (`geoip:ru`, `geoip:private`, домены `.ru`, `.su`,
`.рф`). Экзотические вроде `geosite:ru-available-only-inside` существуют лишь в
русских сборках, и на стандартных ядро Xray не запускается вообще.

Дополнительно установщик подтягивает русские geo-файлы с
[runetfreedom](https://github.com/runetfreedom/russia-v2ray-rules-dat) — списки
становятся точнее. Если скачать не выйдет, останутся стандартные, и всё
продолжит работать.

## Режим TUN

Нужен, если требуется завернуть **весь** трафик: голос в Discord, игры,
приложения со своим сетевым стеком. Без него работают браузеры и обычные
программы, но голосовые каналы в приложении Discord останутся немыми — там
UDP, а системный прокси на UDP не распространяется.

Цена: программу придётся всегда запускать от администратора, а закрывать —
через меню «Выход», иначе в системе останутся виртуальный адаптер и маршруты.

## NetRepair

Если VPN-клиент сломал сеть — «подключено, но интернета нет» — эта утилита
возвращает всё на место: снимает системный прокси, отключает службы и драйверы
VPN-клиентов, сбрасывает правила брандмауэра, Winsock и стек TCP/IP, чистит
маршруты и кэши, отключает «Быстрый запуск» (из-за него лечение слетает после
перезагрузки).

Посмотреть, что она собирается сделать, ничего не меняя:

    NetRepair.exe /dry

Вернуть отключённое обратно (если после лечения перестал подниматься TUN):

    NetRepair.exe /undo

## Сборка из исходников

Обе программы — один файл на C# без внешних зависимостей, собираются
компилятором из состава .NET Framework:

    csc /target:exe /platform:x64 /r:System.dll /r:System.IO.Compression.dll ^
        /r:System.IO.Compression.FileSystem.dll /out:VPN-Setup.exe VPN-Setup.cs

    csc /target:exe /r:System.dll /r:System.ServiceProcess.dll ^
        /win32manifest:app.manifest /out:NetRepair.exe NetRepair.cs

## Предупреждения

Файлы не подписаны сертификатом, поэтому SmartScreen покажет предупреждение:
«Подробнее» → «Выполнить в любом случае».

NetRepair намеренно отключает всё, что похоже на VPN-клиент, включая нужное.
Это инструмент для случая «интернета нет вообще», а не для тонкой настройки.
